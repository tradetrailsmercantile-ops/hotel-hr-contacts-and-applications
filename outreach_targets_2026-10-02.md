# Next execution layer

For each application, the first outreach should be directed to the named HR/recruiting contact when a verified public professional profile exists. The housekeeping leader is the second human route when verified. Hotel social is the third route.

Do not send the same message to everyone. The message should name the exact applied role and application ID.

Recommended message labels:
- HR/Recruiter: application follow-up
- Housekeeping leader: role-specific introduction
- Social DM: brief request to route the application to the hiring team
- Official email: formal backup

No fees should ever be paid for a Hilton recruitment process; Hilton states that it does not request money from applicants.
